# 啾啾日記

記錄情侶之間的美好時刻、烏雲時刻和吵架議題的小網頁 App，用手機瀏覽器打開就能用。

## 現在能做什麼

- **美好時刻、烏雲時刻**：美好時刻有 100 個的進度條；烏雲時刻不設目標，首頁改顯示「美好 : 烏雲」的比例和距離 5 : 1 還差幾個。每則紀錄可以填標題、日期（日曆選單）、描述、多張照片、心情表情（最多 3 個，可自選任何表情）和感受標籤。沒有放照片的美好時刻會顯示預設圖和編號。
- **事後反思**：烏雲時刻可以隨時補寫「事後反思」，記下冷靜之後想法怎麼改變，會依日期排成時間軸（每則 500 字，最多 50 則）。
- **吵架議題**：可以填分類（能自訂）、原因、雙方的想法和狀態（未解決／處理中／已解決），還能一直補充後續。
- **誰可以看**：可以選給對方看、上鎖或任務解鎖（按完成就好／要上傳照片）。美好時刻預設「給對方看」，烏雲時刻和吵架議題預設「上鎖」。雲端版開啟分享碼後就會生效；單人版的上鎖只是標記。改了「誰可以看」之後，解鎖狀態會重設，對方要重新做任務。
- **編輯**：可以換類型（會拿到新類型的新編號）。寫到一半按返回會先確認；新增時會自動存草稿在這支手機，下次新增時問要不要接著寫。兩台裝置同時改同一則時，後存的會先問要不要覆蓋。內容改過會顯示「幾月幾日編輯過」。
- **最近刪除**：刪除的紀錄會先放在設定頁的「最近刪除」30 天，可以救回來或提早永久刪除，30 天後連照片一起自動清掉。這段期間對方也看不到。
- **名字**：第一次打開會請你填自己和伴侶的名字，標題會變成「Jasmine和小明的紀錄」，吵架議題也會顯示「某某的想法」。設定頁可以改，也可以填在一起的日期，首頁會顯示「在一起第 N 天」。
- **放晴**：烏雲時刻心情過去了可以按「已放晴」，列表會標示，也可以取消。
- **印章冊**：美好時刻 1、5、10、30、50、100 個，吵架和好（議題按「已解決」）、烏雲放晴、事後反思、任務解鎖、在一起天數，達到就蓋一個章並跳出慶祝畫面。首頁會提示「再幾個就能拿到下一個章」。
- **一起完成的事**：兩個人一起的待辦清單。主人和另一半都能新增、打勾；另一半只能刪自己加的。完成後可以一鍵「記成美好時刻」，印章冊有「一起完成」。手機版存在這支手機，雲端版存在 wishes 資料表（最多 200 件）。
- **吵架議題兩個人共用（雙人版第一段）**：新的吵架議題一律兩個人都看得到（舊的上鎖議題維持上鎖，主人可以自己打開）。另一半綁定 Email 或 Google 後，可以新增議題、改狀態、寫後續、編輯內容，只能刪自己新增的；主人也不能刪另一半新增的。後續會標是誰寫的。還沒綁定的另一半照舊只能看和寫補充。
- **另一半也能寫自己的紀錄（雙人版第二段）**：綁定帳號的另一半可以新增自己的美好時刻、烏雲時刻（可以放照片），選「給對方看」、「上鎖」或「任務解鎖」。上鎖的只有寫的人看得到，對方只看到「有一則上鎖」。每個人只能改、刪自己寫的。美好 100 個的目標、首頁數字兩個人合計，編號兩個人共用一組，由資料庫發號；列表可以切「全部／我的／對方的」。
- **互相按愛心（雙人版第三段）**：兩個人都能對「對方寫的」美好時刻按愛心，寫的人會看到誰按了。
- **互相出任務、另一半的照片（雙人版第三段）**：兩個人都能出任務給對方，誰寫的紀錄誰審核；退回時可以寫一句原因。另一半的照片放在自己的資料夾，對方只看得到分享或已解鎖紀錄裡的照片；照片額度 30 張兩人共用，任務照片不算。
- **暫停分享**：設定頁一鍵讓另一半暫時看不到你寫的紀錄、照片、任務和清單，對方自己寫的照舊，隨時恢復。
- **結束這段關係**：可以「封存」（收進設定頁的「封存的回憶」，只有自己看得到）或「全部刪除」。兩種都會移除另一半、讓分享碼作廢，數字和編號從頭開始，之後新的另一半看不到封存的紀錄。
- **App 密碼鎖**：設定頁可以開（預設關閉），打開 App、或離開超過 1 分鐘再回來要輸入 4 位數密碼。只鎖這支手機；雲端版忘記密碼可以登出再登入解除。
- **吉祥物啾啾與啵啵**：一對小鸚鵡，出現在首頁、空白頁、烏雲和吵架列表、印章慶祝、放晴。設定頁可以選兩隻的顏色（預設奶油黃 × 霧藍），另一半看到的是主人選的顏色。程式在 `js/mascot.js`。
- **意見回饋**：設定頁的「意見回饋」，訪客、主人、另一半都能送。內容存在 Supabase 的 feedback 資料表，只有你在後台（Table Editor → feedback）看得到；同一帳號一天最多 10 則，全部一天最多 500 則。
- **一年前的今天**：往年同一天有美好時刻的話，首頁會出現回顧卡。
- **管理標籤**：設定頁可以把標籤改名或刪除，所有紀錄一起改。
- **上限**：標題 60 字、描述 2000 字、吵架的原因和想法各 1000 字、解法 500 字、每則後續 300 字且每個議題最多 100 則、標籤每個 12 字且每則最多 10 個、照片每則最多 9 張（原檔最大 20 MB，自動壓縮，雲端每張上限 5 MB）、日期要在 1970 年到今天之間、分類每個 12 字且最多 30 個、名字 20 字、任務 100 字、任務留言 500 字、分享密碼 6 到 72 個字元。
- **編號**：每則紀錄的 No. 在新增時就固定，改日期不會變；刪除後號碼留空，不會補位。設定頁可以依日期重新編號。
- **不用登入就能先用**：新使用者打開就能直接記錄，資料先存在手機。註冊或登入後會自動把這些紀錄搬上雲端。登入過的手機登出後會回到登入畫面。
- **分享碼（雲端版）**：在設定頁填你的名字和分享密碼，產生一組分享碼。你可以複製邀請連結傳給對方（分享碼已經帶在連結裡），對方點開，輸入分享碼、密碼和自己的名字，就能看「給對方看」的紀錄和做任務，不能修改任何東西。對方送出任務後，你在那則紀錄裡按「通過並解鎖」，對方就看得到，對方的列表也會標示「剛解鎖！」。每次有人加入（包括另一半換手機、清掉瀏覽器重新加入）都要你在設定頁按「同意」，首頁也會提醒；同意新的人會取代舊的，所以一組分享碼同時只有一位另一半。另一半看得到有幾則上鎖的紀錄（只有編號，沒有內容），可以對美好時刻按愛心、在吵架議題寫「我的補充」，同一個任務一天最多送 5 次。改分享密碼時可以順便移除已加入的人。你隨時可以移除對方、換新分享碼或停止分享。
- **篩選**：美好和烏雲可以按標籤篩選，吵架議題可以按分類和狀態篩選。
- **備份**：在設定頁可以匯出「還原用備份」（.json，照片也包含在內，用來匯入還原）和「閱讀版」（.html，點開就能瀏覽和列印，可以勾選只匯出給對方看的）。單人版超過 14 天、雲端版超過 30 天沒備份，首頁會提醒。
- **照片額度**：手機版（不登入）照片不限張數，存在手機裡。雲端帳號免費最多 30 張（列表小圖不算），超過會顯示「付費功能・準備中」，按「我有興趣」會記下來。要讓某人不受限制：到 Supabase 的 **Table Editor → plans** 新增一列，owner 填他的使用者 id（在 Authentication → Users 看得到），plan 填 `plus`。想知道多少人有興趣：看 **upgrade_interest** 表。
- **帳號**：Email 登入可以按「忘記密碼」收重設信。雲端版可以在設定頁刪除帳號（會刪掉所有資料）。在 LINE、IG、FB 裡打開時會提醒改用 Safari 或 Chrome。

沒有填雲端設定時，資料只存在這支手機的瀏覽器裡（IndexedDB）。清除瀏覽器資料或換手機之前，請記得先匯出備份。

## 放上網路（GitHub Pages）

1. 到倉庫的 **Settings → Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，然後按 Save
3. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/couple-diary/`
4. 用手機打開網址，接著：iPhone 在 Safari 按「分享 → 加入主畫面」，Android 在 Chrome 按「⋮ → 加到主畫面」，之後就能像 App 一樣從主畫面打開

## 雲端版（Supabase）

填好 `js/config.js` 之後，App 會改成雲端模式：要用 email 和密碼登入，紀錄和照片都存在 Supabase，換手機只要登入就能看到。設定頁可以把手機裡原本的紀錄一鍵搬上雲端。

設定步驟：
1. 在 Supabase 建立專案
2. 到 **SQL Editor** 貼上 `supabase/schema.sql` 的內容並按 Run，這一步會建立資料表、照片空間和安全規則（每個人只能讀寫自己的資料）
3. 到 **Authentication → URL Configuration**，把 Site URL 設成 `https://diary.jas-soul.com/`，這樣確認信的連結才會回到 App
4. 把 **Project Settings → API** 裡的 Project URL 和 anon public key 填進 `js/config.js`

想用 Google 登入的話，還要：
- 在 Google Cloud Console 建立 OAuth 用戶端（網頁應用程式），「已授權的重新導向 URI」填 `https://<專案>.supabase.co/auth/v1/callback`
- 在 Supabase 的 **Authentication → Sign In / Providers → Google** 開啟，貼上 Client ID 和 Client secret
- 在 **Authentication → URL Configuration → Redirect URLs** 加上 `https://diary.jas-soul.com/`

每次程式更新了 `supabase/schema.sql`，都要到 **SQL Editor** 整份重新貼上按 Run 一次（重複執行不會弄壞資料）。

忘記密碼要能用，還要：
- 在 **Authentication → URL Configuration → Redirect URLs** 加上 `https://diary.jas-soul.com/?reset=1`
- 建議在 **Authentication → Sign In / Providers → Email** 把最短密碼長度改成 8

要開放分享碼，還要：
- 在 **SQL Editor** 重新貼上最新的 `supabase/schema.sql` 並按 Run（會新增分享碼、對方名單和任務的資料表）
- 在 **Authentication → Sign In / Providers** 打開 **Allow anonymous sign-ins**（對方加入時用的是不需要 email 的臨時帳號）
- **Allow new users to sign up** 要保持開著，臨時帳號也算新註冊

另一半要綁定帳號（一起寫吵架議題），還要：
- Email 綁定：不用另外設定，另一半會收到確認信，點連結就完成
- Google 綁定：在 **Authentication → Sign In / Providers** 打開 **Allow manual linking**（沒開的話另一半按「用 Google 綁定」會看到提示，改用 Email 就好）

`js/config.js` 裡的兩個值是公開的，放進程式沒關係。service_role（secret）key 千萬不要放進來。

## 在電腦上試用

在這個資料夾執行 `python3 -m http.server`，再打開 http://localhost:8000 就可以了。

## 檔案說明

- `index.html`：頁面骨架
- `css/style.css`：外觀
- `js/config.js`：雲端設定（Supabase 網址和公開金鑰）
- `js/db-local.js`：單人模式的資料儲存（手機瀏覽器的 IndexedDB）
- `js/db-cloud.js`：雲端模式的資料儲存（Supabase），功能和單人模式一樣
- `supabase/schema.sql`：雲端資料表和安全規則
- `vendor/`：Supabase 官方的瀏覽器套件（2.117.2 版），放在這裡就不用靠外部 CDN
- `js/app.js`：所有畫面和操作
- `manifest.json`、`icons/`：加到主畫面時的名稱和圖示

## 資料存在哪裡

- 帳號密碼：Supabase 的登入系統，只存加密雜湊；用 Google 登入的話不存密碼
- 紀錄、設定、分享碼、對方名單、任務：Supabase 資料庫，每個人只讀寫得到自己的（分享碼密碼也只存加密雜湊）
- 照片：Supabase Storage 不公開的 photos 空間（原圖放在 `帳號/照片.jpg`，列表用的小圖放在 `帳號/t/照片.jpg`）
- 草稿：寫到一半的新紀錄只存在這支手機（localStorage），存好或放棄就刪掉

Supabase 免費方案一週沒人用會暫停，App 會顯示連不上雲端；資料沒有不見，到 Supabase 後台按 Restore 就會恢復。免費方案沒有可以下載的自動備份，記得定期匯出。
- 手機：只存登入狀態，不存密碼
